# CTASaham Website

Website profesional untuk platform trading dan edukasi saham CTASaham.

## 🚀 Tech Stack

- **Framework**: Next.js 14 (dengan JSX, tanpa TypeScript)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Deployment**: Vercel

## 📁 Project Structure

```
ctasaham-website/
├── pages/              # Halaman website
│   ├── _app.js        # Main app component
│   ├── _document.js   # Custom document
│   ├── index.js       # Homepage
│   ├── tentang-kami.js
│   ├── layanan.js
│   ├── analisis.js
│   ├── paket-harga.js
│   └── kontak.js
├── components/         # Reusable components
│   ├── layout/
│   │   ├── Header.jsx
│   │   ├── Footer.jsx
│   │   └── Layout.jsx
│   └── sections/
├── styles/
│   └── globals.css    # Global styles & Tailwind
├── public/            # Static assets
│   ├── images/
│   │   ├── logo.png
│   │   └── founder.jpg

```

## 🛠️ Installation & Setup

1. Install dependencies:
```bash
npm install
```

2. Run development server:
```bash
npm run dev
```

3. Open browser: `http://localhost:3000`

## 📦 Build for Production

```bash
npm run build
npm start
```

## 🚀 Deploy to Vercel

1. Push code to GitHub
2. Import project di Vercel
3. Deploy automatically!
